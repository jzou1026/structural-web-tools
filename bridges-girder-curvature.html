Theory & Documentation

Part 1: Engineering Theory

1. Structural idealization

The girder is represented as a one-dimensional, small-deflection Euler-Bernoulli beam with simple vertical supports at each span boundary. The first and last supports carry no applied end moment. Internal supports enforce zero vertical displacement while permitting continuous rotation and bending moment.

\[\kappa(x)=\frac{M(x)}{E I(x)}+K_a(x)\]Equation 1

where \(\kappa(x)=d^2y/dx^2\) is total curvature, \(M(x)\) is bending moment, \(E I(x)\) is flexural rigidity, and \(K_a(x)\) is the imposed curvature assigned to a segment.

2. Relative flexural rigidity

A reference rigidity \(EI_{ref}\) is introduced. The span input \(r_i\) is the relative rigidity \(EI_i/EI_{ref}\). The state variable \(m=M/EI_{ref}\) therefore contributes \(m/r_i\) to curvature.

\[r_i=\frac{EI_i}{EI_{ref}},\qquad \frac{M}{EI_i}=\frac{m}{r_i}\]Equation 2

where \(r_i\) is the relative flexural rigidity of span \(i\), \(EI_i\) is the span rigidity, \(EI_{ref}\) is an arbitrary common reference rigidity, and \(m=M/EI_{ref}\). Only relative stiffness is needed for curvature-induced deformation and reaction distribution.

3. First-order governing system

\[\frac{dy}{dx}=\theta,\qquad \frac{d\theta}{dx}=\frac{m}{r_i}+K_a(x),\qquad \frac{dm}{dx}=v,\qquad \frac{dv}{dx}=0\]Equation 3

where \(y\) is vertical deflection, \(\theta\) is section rotation, \(m=M/EI_{ref}\), \(v=V/EI_{ref}\), and \(r_i\) is the active span relative rigidity. In the absence of transverse distributed force, normalized shear is constant between supports.

4. Curvature input function

\[K_a(x)=\sum_{j=1}^{n_c}K_j\,I_j(x)\]Equation 4

where \(K_j\) is the curvature entered for segment \(j\), \(n_c\) is the number of curvature segments, and \(I_j(x)\) equals 1 inside the segment and 0 elsewhere. If segments overlap, their curvatures are superimposed.

5. Support and end conditions

\[y(x_s)=0\quad\text{at every support},\qquad m(0)=m(L)=0\]Equation 5

where \(x_s\) is a support coordinate and \(L\) is total girder length. Internal vertical reactions are represented by jumps in \(v\), while \(y\), \(\theta\), and \(m\) remain continuous.

6. Shooting solution

For \(n\) spans, the unknown vector contains the initial rotation, initial normalized shear, and \(n-1\) internal-support shear jumps. The application evaluates one zero trial and one unit trial for each unknown, assembles a linear influence matrix, and solves for the unknowns so that Equation 5 is satisfied.

\[\mathbf{A}\mathbf{u}=-\mathbf{r}_0\]Equation 6

where \(\mathbf{A}\) is the residual influence matrix, \(\mathbf{u}\) is the shooting unknown vector, and \(\mathbf{r}_0\) is the residual produced by the zero trial.

7. Runge-Kutta integration

\[\mathbf{s}_{k+1}=\mathbf{s}_k+\frac{\mathbf{k}_1+2\mathbf{k}_2+2\mathbf{k}_3+\mathbf{k}_4}{6}\]Equation 7

where \(\mathbf{s}_k=[y,\theta,m,v]^T\) is the state at integration point \(k\), and \(\mathbf{k}_1\) through \(\mathbf{k}_4\) are the classical fourth-order Runge-Kutta increments. Steps terminate exactly at support and curvature-segment boundaries.

8. Deflection table sampling

\[x_{i,j}=x_i+\frac{j}{n_p}L_i,\qquad j=0,1,\ldots,n_p\]Equation 8

where \(x_{i,j}\) is table point \(j\) in span \(i\), \(x_i\) is the span start coordinate, \(L_i\) is the span length, and \(n_p\) is the user-selected number of equal intervals per span. Shared support coordinates are listed once.

\[y(x)=y_a+\frac{x-x_a}{x_b-x_a}\left(y_b-y_a\right)\]Equation 9

where \(y(x)\) is the reported deflection, \(x_a\) and \(x_b\) are adjacent numerical integration stations bracketing the requested table coordinate, and \(y_a\) and \(y_b\) are their calculated deflections. Equation 9 is also applied to rotation for the exported table.

Part 2: Coding Theory

The application is a standalone HTML file. JavaScript stores editable span and curvature-segment arrays, derives support coordinates cumulatively from span lengths, validates positive lengths and relative rigidities, and calculates the active curvature and stiffness at each integration coordinate. A generic linear shooting solver supports any practical number of spans. Results are sampled into arrays and rendered as responsive SVG graphics for girder geometry, deflection, total curvature, imposed curvature, and normalized internal actions. The deflection-table module creates equal subdivisions independently in every span, removes duplicate shared-support rows, interpolates deflection and rotation from the RK4 history using Equation 9, renders a scrollable table, and exports the same rows to CSV. The full-state CSV export writes the complete numerical integration history. The working-file command clones the current document and embeds the current arrays and scalar inputs into a downloadable HTML file.

The print routine first requests MathJax typesetting and waits for completion before opening the browser print dialog. Print CSS prevents equations, charts, and result cards from being split awkwardly across pages.
