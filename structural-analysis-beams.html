Theory & Documentation

This section documents the mechanics and processing logic implemented by the application. The analysis represents the bridge as a one-dimensional, linearly elastic Euler-Bernoulli beam system assembled by the direct stiffness method. Results apply only to the idealized model and should be independently verified before design use.

Part 1: Engineering Theory

1. Structural idealization and degrees of freedom

Each span is one prismatic beam element. Plane sections are assumed to remain plane; transverse shear deformation, geometric nonlinearity, material nonlinearity, and torsion are excluded. Each node has one vertical translation and one rotation:

de=[viθivjθj]TEquation 1

where de is the element displacement vector, vi and vj are the vertical translations at the element's left and right nodes, and θi and θj are the corresponding nodal rotations.

2. Euler-Bernoulli flexure

M(x)=EId2v(x)dx2Equation 2

where M(x) is bending moment at position x, E is Young's modulus, I is the second moment of area, and v(x) is transverse displacement. The program accepts Young’s modulus E and strong-axis second moment of area Ix separately for each span and computes the flexural rigidity as EIx.

3. Element stiffness matrix

ke=EIL3[126L−126L6L4L2−6L2L2−12−6L12−6L6L2L2−6L4L2]Equation 3

where ke is the local element stiffness matrix, E is Young’s modulus, Ix is the strong-axis second moment of area, and L is element length. The program adds each coefficient to the associated positions in the global stiffness matrix.

4. Consistent nodal loading

A full-span uniformly distributed load is converted to the following equivalent nodal vector:

fe,q=[qL/2qL2/12qL/2−qL2/12]TEquation 4

where fe,q is the element load vector, q is uniform load intensity, and L is element length.

An axle within an element is distributed to its nodes using cubic Hermitian shape functions:

ξ=aL,N1=1−3ξ2+2ξ3,N2=L(ξ−2ξ2+ξ3),N3=3ξ2−2ξ3,N4=L(−ξ2+ξ3)Equation 5

where ξ is the dimensionless local coordinate, a is the axle distance from the element's left node, L is element length, and N1 through N4 are the beam interpolation functions.

fe,P=P[N1N2N3N4]TEquation 6

where fe,P is the consistent element load vector for one axle, P is axle load, and N1 through N4 are defined by Equation 5. All active axle and distributed-load vectors are combined by linear superposition.

5. Global solution and support reactions

KD=FEquation 7

where K is the assembled global stiffness matrix, D is the global displacement vector, and F is the assembled nodal load vector. Pin supports restrain vertical translation, fixed supports restrain translation and rotation, and free nodes restrain neither. The reduced free-degree system is solved by Gaussian elimination.

R=KD−FEquation 8

where R is the global residual vector containing restrained-degree reactions, while K, D, and F retain the definitions given for Equation 7. Reported reaction signs follow the application's display convention.

6. Shear and moment recovery

Element end forces are recovered from the stiffness response minus the element's consistent load vector. Internal actions are then evaluated from section equilibrium at 121 equally spaced points per element:

V(x)=V0−qx−∑ar≤xPrEquation 9

where V(x) is shear at local coordinate x, V0 is recovered left-end shear, q is uniform load intensity, Pr is axle load r, and ar is that axle's local coordinate.

M(x)=−M0+V0x−qx22−∑ar≤xPr(x−ar)Equation 10

where M(x) is bending moment at local coordinate x, M0 is recovered left-end element moment, V0 is recovered left-end shear, q is uniform load intensity, Pr is axle load r, and ar is its local coordinate. Linear interpolation maps the recovered values to table stations.

7. Moving-load path and envelopes

xr(p)=p−srEquation 11

where xr(p) is the global bridge position of axle r at vehicle-position parameter p, and sr is that axle's offset from Axle 1. An axle is active only when 0≤xr(p)≤Lbridge, where Lbridge is total bridge length.

pn=p0+nΔpEquation 12

where pn is the vehicle position for load case n, p0 is the initial position, Δp is the user-entered nudge distance, and n is a nonnegative integer. The script appends an exact final position so the last axle reaches the right end.

Emax(xj)=maxnEn(xj),Emin(xj)=minnEn(xj)Equation 13

where En(xj) is a response in case n at reporting station xj, and Emax(xj) and Emin(xj) are its upper and lower envelopes. Equation 13 is applied independently to moment, shear, deflection, and support reactions.

8. Numerical scope and verification

  • The nudge distance governs the moving-load search resolution. Critical results should be checked for convergence using smaller values of Δp.
  • Span divisions define results-table stations, while internal-force recovery uses 120 intervals per span.
  • The analysis does not automatically apply load combinations, load factors, dynamic allowance, lane distribution, resistance factors, section-capacity equations, second-order effects, or nonlinear response.
  • Continuity and support conditions must represent a stable structure. A singular reduced stiffness matrix triggers an error.
Part 2: Coding Theory

The program is a standalone HTML application. CSS controls the screen and report layouts; JavaScript stores the model, performs matrix calculations, generates SVG diagrams and tables, exports CSV data, and saves a new working HTML file.

  1. State and inputs: arrays hold axles, support-to-support spans, nested stiffness members, and supports. Editable controls update the associated objects without running the solver. Analysis starts only when the user clicks Analyze.
  2. Geometry: cumulative span lengths generate global node coordinates and output stations.
  3. Moving-load loop: Equation 12 generates vehicle positions. Equation 11 maps each axle to a global coordinate, after which active axles are assigned to a span and local coordinate.
  4. Assembly: the script creates each element matrix from Equation 3 and load vectors from Equations 4 and 6, then assembles them into the global system in Equation 7.
  5. Boundary conditions and solver: restrained and free degrees of freedom are separated. Gaussian elimination solves the reduced system, with a singularity check for unstable models.
  6. Post-processing: Equation 8 yields reactions. Equations 9 and 10 recover shear and moment. Deflection is recovered from the cubic Hermitian element displacement field using the solved nodal translations and rotations. Linear interpolation evaluates responses at reporting stations.
  7. Envelope storage: each case updates the maximum and minimum response arrays according to Equation 13 and records the cases governing moment and deflection extrema.
  8. Rendering and export: the output object feeds the summary cards, tables, beam preview, SVG moment, shear, and deflection envelope diagrams, the iteration log, and CSV export.
  9. PDF report: Save PDF Report reruns the model, exposes all required report panels, waits for MathJax startup and typesetting to complete, allows two browser paint frames plus a short delay, and then opens the browser print dialog.
  10. Persistence: Save Working File clones the complete document, including this marked theory section, MathJax configuration, styles, equations, and print logic, and replaces only the saved input-state constant. Future source updates should retain all blocks marked PERSISTENT THEORY.
